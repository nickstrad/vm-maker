# User preferences

- For visual or layout work, capture and inspect rendered screenshots/snapshots before calling the work complete. Check spacing, readability, clipping, overlap, and cramped layouts at the intended display size; for responsive interfaces, also check a narrower viewport. Fix problems and inspect a fresh snapshot after changes. Source inspection or successful rendering alone does not count as visual validation.
- If the target, renderer, or referenced images are unavailable, state that visual validation is still pending and request the missing input. Never claim to have inspected inaccessible screenshots.
